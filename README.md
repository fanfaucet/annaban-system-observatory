# AnnabanAI System Observatory

Official source-of-truth dashboard for the AnnabanAI governance-focused AI systems architecture and product framework associated with Jacob Wayne Kinnaird.

## Purpose

Provides a continuously updating, unified view of:

- **Core Systems**: AnnabanAI, AetherOS, SparkAI, SparkOS
- **Operational Stacks**: Heritage Stack, DDS-Core, Mission Stack
- **Modules**: Negotiation, Audit, Valuation Engine, Quantum Entertainment SDK, Backend–Frontend Fusion, Deployment Pipeline
- **Governance & Controls**: human-in-the-loop defaults, resilience, oversight flows

All status data is generated as **simulated / conceptual** unless independently verified.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Client-side polling of `/api/status-feed` every 15 seconds

## Local Development

```bash
npm install
npm run dev
```
